Thông Tin Chung

  • This function shows you total bets on home/away team and provides forecasts for the amount you might win/lose on matches that have ‘Money Line’ bets.

Bộ Lọc Tìm Kiếm

  • Tiền Tệ: lọc các vé được đặt theo đơn vị tiền tệ đã chọn.
    • Tất Cả: Liệt kê vé cược của tất cả đơn vị tiền tệ được hỗ trợ.
  • Tiền Tệ Cơ Sở: chuyển tất cả dữ liệu sang tiền tệ cơ sở nhằm mục đích tham chiếu.

Hướng Dẫn Sử Dụng Báo Cáo

    {match-monitoring-section}
  • Monitor: Click the “+” icon to add the event to the monitoring list.
    The “+” icon will only be shown for events that have Full Time tickets.
    If the event has already been added to the monitoring list, the text “Added” will be displayed instead.
  • Event: Click the Event link to add the event to the monitoring list and open the Match Monitoring Center page.
    The hyperlink will only be displayed for events that have Full Time tickets.
    • {/match-monitoring-section}
  • Total Home: Total bets on home team.
    Total Home = Home stake * odds
  • Total Away: Total bets on away team.
    Total Away = Away stake * odds
  • Forecast Home: The amount that Licensee might win/lose if home team/members win.
    Forecast Home = Home stake * odds – away stake
    • A negative number (e.g. -10) indicates Licensee will win if home team wins.
    • A positive number (e.g. 10) indicates Licensee will lose if home team wins.
  • Forecast Away: The amount that Licensee might win/lose if away team/members win.
    Forecast Away = Away stake * odds – home stake
    • A negative number (e.g. -10) indicates Licensee will win if away team wins.
    • A positive number (e.g. 10) indicates Licensee will lose if away team wins.
  • Notice: if |odds| < 1, odds = 1.
