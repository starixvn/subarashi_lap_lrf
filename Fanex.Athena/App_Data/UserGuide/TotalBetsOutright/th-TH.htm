ข้อมูลทั่วไป

  • This function provides forecasts for 'Outright' bets.

ตัวกรองการค้นหา

  • สกุลเงิน: กรองตั๋วที่อยู่ในสกุลเงินที่เลือก.
    • ทั้งหมด: ตั๋วของสกุลเงินที่รองรับทั้งหมดจะแสดงในรายการ.
  • สกุลเงินหลัก: แปลงข้อมูลทั้งหมดเป็นสกุลเงินที่ใช้อ้างอิงเท่านั้น.

ตัวชี้การรายงาน

  • Team: team/player name. Click to view Bet List of selected team/player.
  • Balance: sums up all stakes of a team/player.
  • Forecast: predicts licensee win loss if a team/player wins.
    • A ตัวเลขที่เป็นลบ (เช่น –10) แสดงว่าผู้ได้รับอนุญาตจะชนะมากกว่าแพ้.
    • A จำนวนบวก (เช่น 10) แสดงว่าผู้ได้รับอนุญาตจะแพ้มากกว่าชนะ.
