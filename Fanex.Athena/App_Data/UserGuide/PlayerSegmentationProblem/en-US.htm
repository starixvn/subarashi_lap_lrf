General Info

  • The report lists out all problem players who have abnormal bet.
  • Enter date ranges in Mark Date filter to view list of problem players who have the first event date that they are changed to problem player.
  • Tick on Get All filter to get all problem players.
  • Enter system ID or external ID in "Username" filter to view specific player.
  • Allow to filter problem players by reason
  • Select Base Currency to convert "Reduced Max Per Event" and “Reduced Max Per Bet” column in the report to the selected base currency.

Report Guidelines

  • External ID: The username registered by ticket owner.
  • System ID: The Numeric sequential ID generated from system for each player.
  • Reduced Max Per Event: The value of Max Per Event after reducing bet setting.
  • Reduced Max Per Bet: The value of Max Per Bet after reducing bet setting.
  • Reason: Show all problem reasons, grouped by each reason. Each reason shall be shown with the first date the event.
  • Mark Date: Show the first event date that a player is changed to a Problem Player.
  • VIP: Show VIP status of the selected player and also allow to change the status for the selected player.
