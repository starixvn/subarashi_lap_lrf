General Info

  • The report displays all figures in Saba Coins.
  • This report supports up-to-date data. You can filter data up to 3 months per query.

Search Filters

  • Username: Enter the external ID or system ID of the searched account.
    • Note that, if you have not specified any Player account then the Report will list out data of all Players within the selected date range.
  • Currency: Select the currency which data will be retrieved.
    • All: All supported currencies will be listed out.
  • Exclude Test Data: Excludes all tickets from test account.

Report Guidelines

  • External ID: the username registered by ticket owner.
  • System ID: the Numeric sequential ID generated from system for each account.
  • Opening Balance: this is Player Opening Balance, the amount of funds in Player account at the beginning of a day. Note that report will take From date as the date to retrieve data for Opening Balance.
  • Reward/ Promotion: the Reward and Promotion amount is given to player.
  • Exchange To Cash: Player exchanges Saba Coins to Cash.
  • Turnover: Total Player turnover within selected filters.
  • Pending Funds: total stake of running tickets.
  • Player W/L: the amount player won or lost based on their bets.
  • Closing Balance: this is Player Closing Balance, the amount of funds at the end of a day.
    Closing Balance = Opening Balance + Reward/ Promotion + Exchange To Cash – Pending funds + Player W/L
