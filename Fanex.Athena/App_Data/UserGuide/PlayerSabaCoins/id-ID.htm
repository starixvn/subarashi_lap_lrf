Informasi Umum

  • Laporan ini menampilkan semua angka dalam Koin Saba.
  • Laporan ini mendukung data terkini. Anda dapat memfilter data hingga 3 bulan per permintaan.

Filter Pencarian

  • Username: Masukkan ID eksternal atau ID sistem akun yang dicari.
    • Perhatikan bahwa, jika Anda tidak menentukan akun Pemain mana pun, maka Laporan akan mencantumkan data semua Pemain dalam rentang tanggal yang dipilih.
  • Mata Uang: pilih mata uang dimana data akan diambil.
    • Semua: semua mata uang yang didukung akan terdaftar.
  • Kecualikan Data Uji: Mengkecualikan semua tiket dari akun uji.

Panduan Laporan

  • ID Eksternal: username yang terdaftar oleh pemilik tiket.
  • ID Sistem: ID berurutan numerik yang dihasilkan dari sistem untuk setiap akun.
  • Saldo Awal: ini adalah Saldo Awal Pemain, jumlah dana dalam akun Pemain di awal hari. Perhatikan bahwa laporan akan mengambil tanggal Mulai sebagai tanggal untuk mengambil data Saldo Awal.
  • Hadiah/ Promosi: Jumlah hadiah dan promosi yang diberikan kepada pemain.
  • Menukarkan ke Uang: Pemain menukar koin menjadi uang tunai.
  • Omset: Omset Pelanggan setiap harinya dalam rentang tanggal yang dipilih.
  • Dana Tertunda: total taruhan yang sedang berjalan.
  • Pemain W/L: Jumlah yang dimenangkan atau hilang oleh pemain berdasarkan taruhan mereka.
  • Saldo Akhir: ini adalah Saldo Akhir Pemain, jumlah dana pada akhir hari.
    Saldo Akhir = Saldo Awal + Hadiah/Promosi + Penukaran ke Uang Tunai – Dana Tertunda + W/L Pemain
