General Info

  • The report contains only abnormal bet tickets and related information such as: League, Match, IP, Location, Reason,...
  • This report supports up-to-date data. You can filter data up to 3 months per query.
  • OANDA Exchange Service will use the exchange rate of the end date of each selected month when converting the figures.

Search Filters

  • View in Detail: Support search by Ref No, Currency, Base Currency and Convert all figures to Base Currency.

Report Guidelines

  • View in Detail: All information on each abnormal bet ticket based on selected date range: Ref No, Stake, Reason,...
  • View in Summary: Total abnormal bet tickets based on selected date range.
  • View in IP Summary: All IP and location of last login and tickets of each player based on selected date range.
