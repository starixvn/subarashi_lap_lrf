Informasi Umum

  • This function allows you to view created/last transaction time of customer and manage setting changes in customers.

Filter Pencarian

  • Username: search by External ID or System ID.
  • View by: view changes of all settings or a specific setting such as BA, Status, Special Level and Currency.
  • View data in month: view logs within a specific month.
  • Show old values: show Old values of changes. Old values will be highlighted with red color.

Panduan Laporan

  • General: view login history of a customer.
    • Created Date: date time that customer was created.
    • Last Txn: last transaction date
  • Customer Setting: manage changes of settings in customers’ accounts.
  • Group Commission: manage changes of group commission of customers.
  • Product Info:
    • SB: Sportsbook
    • NG: Number Game
    • CS: Casino
