General Info

  • The report only supports for Sportsbook.
  • The purpose of this report is to enable Licensee to monitor the last 10, 20 or 30 running tickets of their customers.
  • The report refreshes automatically every 3 seconds. To stop automatic refresh, click Freeze button.

Search Filters

  • Sport: All offered sports of the selected licensee will be displayed in the dropdown list.
    • The data displayed in the dropdown list for League and Match selection must match with your choices for "Sport type”.
    • If You select more than 1 league, League filter will be disabled.
    • If You select more than 1 sport, Match filter will be disabled.
  • Show/hide: selects the columns to show / hide in the report.
  • Live Status: the ticket status that will be listed out. Note that Mix Live & Non-Live status is used for Parlay Sport.
  • Odds type: the format which odds value will be displayed.
    • All: keeps the original Odds of all tickets.
    • Based DEC/MY: only convert odds come with bet types Handicap, Odd/Even, Over/Under and Money Line to Decimal / MY. Odds come with other bet types are shown as original odds (the odds don't have name).
  • Special Level: the level of the customer (player) that will be monitored (1 is lowest and 10 is highest). The bet list shall display the text of ExternalID and SystemID follow color that special customer (player) are set on the Player Administration function.
  • Currency: selects offered currencies of the bet tickets that will be listed out in the report.
  • Base Currency: convert all data to based currency for reference only.
  • Stake range: filter tickets that have stakes placed in selected range.
    • From is empty, it means that From = 0 (show all tickets which have Stake =< To)
    • To is empty, it means that To = unlimited (show all tickets which have Stake >= From)
    • Note that: Max length of number is 9 digits by default. If both From and To are empty, it means “no limit stake”.
  • Time Zone: selects the Time Zone to which transaction time of all tickets will be converted.
  • Platform: the platform that members used to place bets, select a specific platform that you want to monitor.
  • Risk Level: selects the Risk Level type which data will be retrieved.

Report Guidelines

  • Platform: the platform that Customers used to place bets.
  • External ID: the username registered by ticket owner.
  • System ID: the Numeric sequential ID generated from system for each account.
  • Trans. Time: a unique reference number given to each bet in the system, each attached with a timestamp of the time and date the bet is accepted.
  • Choice: shows detail information of Bet ticket such as bet type, selected team, match name, and league of the match.
  • Odds: displays the fixed odds value of each ticket.
  • Stake: the amount of money that Customer has bet on each ticket.
  • Status: shows the status of bet ticket.
