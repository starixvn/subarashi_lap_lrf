General Info

  • This function shows all bets which have Mix Parlay and System Parlay bet types and the details of each single bet.
  • Mix Parlay/System Parlay tabs: switch between Mix Parlay and System Parlay bet lists.

Search Filters

  • Currency: filters tickets placed in selected currency.
    • All: tickets of all supported currencies will be listed out.
  • Base Currency: Convert all data to base currency for reference only.

Report Guidelines

  • External ID: The username registered by the ticket owner.
  • System ID: The Numeric sequential ID generated from the system for each account.
  • Trans.Time: a unique reference number given to each bet ticket in the system including a timestamp of the time and date that the ticket was accepted.
  • Choice: click Mix Parlay/System Parlay to show details of sub-tickets such as customer choice, bet type, betting product, match and league.
    • Details (in System Parlay): displays results of settled bets.
  • Odds: multiply the single bet odds together.
  • Stake: sum of all stakes of each outcome.
  • Status: display status of ticket.
