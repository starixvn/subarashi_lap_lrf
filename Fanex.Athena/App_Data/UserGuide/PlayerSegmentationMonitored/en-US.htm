General Info

  • This function supports Sportsbook data only.
  • Accumulated Player Win Loss is only counted when a winning threshold is set. It will be reset daily or when player is removed out of the monitored player list.
  • Accumulated Player Win Loss will be counted right after the ticket is settled. Once a ticket is already settled and accumulated, moving a yesterday un-settled event to the next day won’t change the accumulation.

Report Guidelines

  • External ID: The username registered by the ticket owner.
  • System ID: The Numeric sequential ID generated from system for each player.
  • Currency: Player's original currency.
  • Current Winning Threshold: Winning threshold of player, the threshold is based on player's original currency. User can edit the threshold by clicking on Edit icon.
  • No. of Reached: Number of times that player's accumulated win loss reaches the winning threshold within Reached Threshold from date and to date, clicking on the number of times will display notification history. The count time and notification history only support data within 3 previous months.
  • Last Reached Threshold Date (GMT -4): The last time date when player's accumulated win loss reaches the winning threshold within Reached Threshold from date and to date.
  • VIP Player: Player's VIP status.
  • Action: Support to remove a player out of the list.
  • Notification History: Display notification history based on the Reached Threshold from date and to date. If there is no Reached Threshold Date selected, display all notifications that player reached within 3 previous months.
    • Date: The datetime when player's accumulated win loss reached the winning threshold.
    • Daily Winning Threshold: The winning threshold at the time when player's accumulated win loss reached.
    • Total Winning Amount: The player's accumulated win loss when it reached the winning threshold.
