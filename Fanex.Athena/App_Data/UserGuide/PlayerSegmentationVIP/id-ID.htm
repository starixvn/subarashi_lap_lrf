Informasi Umum

  • Fungsi ini memungkinkan untuk mengelola pemain VIP.
  • Masukkan ID sistem atau ID eksternal pada filter "Username" untuk melihat pemain tertentu.
  • Filter "Tanggal Tanda Level Risiko Terakhir" harus mendapatkan semua tanggal secara default. Jika Anda ingin mencari daftar pemain berdasarkan rentang tanggal tertentu, maka pilih opsi "Pilih Rentang Tanggal".

Panduan Laporan

  • ID Eksternal: username yang terdaftar oleh pemilik tiket.
  • ID Sistem: ID numerik berurutan yang dihasilkan dari sistem untuk setiap pemain.
  • Tingkat Risiko: Menunjukkan Tingkat Risiko ditugaskan untuk setiap pemain.
  • Tanggal Tanda Tingkat Risiko Terakhir: Tampilkan Tanggal Tanda Tingkat Risiko Terakhir untuk setiap pemain.
  • VIP: Menampilkan status VIP dari pemain yang dipilih dan juga memungkinkan untuk mengubah status untuk pemain yang dipilih.

Fungsi Lainnya

  • Tombol Aktivasi VIP: Pilih satu atau beberapa pemain kemudian klik tombol ini untuk mengaktifkan pemain yang dipilih.
  • Tombol Nonaktifkan VIP: Pilih satu atau beberapa pemain kemudian klik tombol ini untuk menonaktifkan pemain yang dipilih.
  • Unggah Daftar VIP: Klik tombol ini untuk mengunggah daftar pemain VIP.
