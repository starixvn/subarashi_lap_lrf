ข้อมูลทั่วไป

  • รายงานแสดงรายการตั๋ว (ยกเว้นแข่งขัน) ของผู้เล่นทั้งหมดในผลิตภัณฑ์ที่เลือก.
  • สามารถเข้าถึงข้อมูลย้อนหลังได้สูงสุด 3 ปี ช่วงเวลาการค้นหาสูงสุดคือ 1 เดือน.
  • ตัวกรองลีกและการแข่งขันใช้ได้เฉพาะกับสปอร์ตบุ๊ค ในบางวันเท่านั้น.
  • หากต้องการดูตั๋วของผู้เล่นรายใดรายหนึ่ง ให้ป้อน รหัสระบบหรือ รหัสภายนอกของผู้เล่นรายนั้นในตัวกรอง "ชื่อผู้ใช้"
  • เลือกสกุลเงินหลักเพื่อแปลงแถว "ทั้งหมด" ในรายงานเป็นสกุลเงินหลักที่เลือก.
  • เมื่อไม่ได้เลือก"แปลงตัวเลขทั้งหมดเป็นสกุลเงินหลัก" ตัวเลขทั้งหมดจะแสดงเป็นสกุลเงินดั้งเดิม (ยกเว้นแถวผลรวม).
  • ใช้ตัวกรอง "แทงบอลสด" เพื่อดึงตั๋วที่แทงบอลสดหรือไม่แทงบอลสด โปรดทราบ: สถานะ แทงบอลสดผสม & ไม่แทงบอลสดใช้สำหรับตั๋ว พาร์เลย์.
  • "สถานะ" filter has won, lost, draw are default. To query more data, please select other options in dropdown list.

  • การถอนเงินสด: เปิดใช้งานเมื่อคุณเลือกผลิตภัณฑ์การพนันกีฬา.
    • รวมการเงินสดออกในสปอร์ตบุ๊ค: พื้นที่ข้อมูลควรแสดงสปอร์ตบุ๊ครวมถึงตั๋วเงินสดออก.
    • ยกเว้นการเงินสดออกจากการเดิมพันกีฬา: พื้นที่ข้อมูลควรแสดงการเดิมพันกีฬาโดยไม่รวมตั๋วเงินสดออก.
    • ดูเฉพาะการเงินสดทันที: ตัวกรองผลิตภัณฑ์ควรเลือกผลิตภัณฑ์สมุดกีฬาโดยอัตโนมัติและยกเลิกการเลือกผลิตภัณฑ์อื่น ข้อมูลจะได้รับเฉพาะตั๋วเงินสดทันที.

ตัวชี้การรายงาน

  • รหัสภายนอก: ชื่อผู้ใช้ที่ลงทะเบียนโดยเจ้าของตั๋ว.
  • รหัสระบบ: รหัสลำดับตัวเลขที่สร้างจากระบบของแต่ละบัญชี.
  • หมายเลขอ้างอิง: หมายเลขอ้างอิงเฉพาะที่กำหนดให้กับการเดิมพันแต่ละครั้งในระบบ.
  • เวลาส่ง: เวลาและวันที่รับเดิมพัน.
  • ตัวเลือก: แสดงข้อมูลรายละเอียดของตั๋วเดิมพัน เช่น วันที่และเวลาของ K.O ในการแข่งขัน (สำหรับสปอร์ตบุ๊คเท่านั้น) ประเภทการเดิมพัน ทีมที่เลือก การแข่งขัน และชื่อลีก.
  • อัตราต่อรอง: แสดงค่าอัตราต่อรองคงที่ของตั๋วแต่ละใบ.
  • ประเภทอัตราต่อรอง: รูปแบบอัตราต่อรองของตั๋วแต่ละใบ.
  • เงินเดิมพัน: จำนวนเงินที่ผู้เล่นวางเดิมพันในแต่ละตั๋ว.
  • สถานะ: แสดงสถานะของตั๋วเดิมพัน.
  • ชนะแพ้/ค่าคอมมิชชั่น: แสดงการแพ้ชนะของผู้เล่นและค่าคอมมิชชั่นที่ได้รับจากผู้ได้รับอนุญาต.
  • ชนะแพ้/ค่าคอมมิชชั่นของผู้ได้รับอนุญาต: จำนวนเงินที่สูญเสียทั้งหมดของผู้ได้รับอนุญาตได้ตัดสินกับผู้เล่นรวมถึงค่าคอมมิชชัน.
  • แพลตฟอร์ม: แพลตฟอร์มที่ผู้เล่นใช้ในการวางเดิมพัน.
  • แทงบอลสด: แสดงตั๋วแทงบอลสดหรือไม่แทงบอลสด.
