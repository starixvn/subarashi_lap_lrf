General Info

  • The report lists out non-settled tickets of all Players on selected products.
  • Select Base Currency to convert "Total" row in the report to the selected base currency.
  • When "Convert all figures to base currency" option is unchecked, all figures are displayed in original currencies (except the Total row).
  • To view tickets of a particular Player, enter system ID or external ID of that Player in "Username" filter.
  • Using "Status" filter to retrieve tickets that are Running, Result Pending or Under-Settlement.

Report Guidelines

  • External ID: The username registered by ticket owner.
  • System ID: The Numeric sequential ID generated from system for each account.
  • Ref.No: A unique reference number given to each bet in the system..
  • Trans. Time: The time and date when the bet is accepted.
  • Choice: Shows detail information of Bet ticket such as K.O date and time of the match (only for Sportsbook), bet type, selected team, match and league name.
  • Odds: Displays the fixed odds value of each ticket.
  • Odd type: The odds format of each ticket.
  • Stake: The amount of money that Player has bet on each ticket.
  • Status: Shows the status of bet ticket.
  • Win Loss/Comm: Shows the player’s win loss and the commission given by Licenseet.
  • Licensee WL/Comm: The total win loss amount Licensee has settled with Player including Comm.
  • Platform: The platform that Player used to place bets.
  • Live: Shows the ticket is Live or Non-Live.
