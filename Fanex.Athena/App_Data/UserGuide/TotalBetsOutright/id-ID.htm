Informasi Umum

  • This function provides forecasts for 'Outright' bets.

Filter Pencarian

  • Mata Uang: menyaring tiket yang ditempatkan dalam mata uang yang dipilih.
    • Semua: tiket dari semua mata uang yang didukung akan ditampilkan.
  • Mata Uang Dasar: Mengonversi semua data ke mata uang dasar hanya untuk referensi.

Panduan Laporan

  • Team: team/player name. Click to view Bet List of selected team/player.
  • Balance: sums up all stakes of a team/player.
  • Forecast: predicts licensee win loss if a team/player wins.
    • Angka negatif (misalnya -10) menunjukkan bahwa Penerima Lisensi akan menang lebih banyak daripada kalah.
    • Angka positif (misalnya 10) menunjukkan bahwa Penerima Lisensi akan kalah lebih banyak daripada menang.
