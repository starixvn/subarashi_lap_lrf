General Info

  • The function allows to manage VIP player.
  • Enter system ID or external ID in "Username" filter to view specific player.

Report Guidelines

  • External ID: The username registered by ticket owner.
  • System ID: The Numeric sequential ID generated from system for each player.
  • VIP: Show VIP status of the selected player and also allow to change the status for the selected player(s).

Other Functions

  • Activate VIP button: Select one or multiple players then clicking on this button to activate the selected player(s).
  • Deactivate VIP button: Select one or multiple players then clicking on this button to deactivate the selected player(s).
  • Upload VIP List: Clicking on this button to upload a list of VIP players.
