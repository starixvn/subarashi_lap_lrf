General Info

  • The report lists out booked bet tickets.
  • This report supports up to 7 days.
  • Username: Enter the external ID or system ID of the searched account.
  • Support searching tickets by Book ID or Ref No or Username.
  • Select Base Currency to convert "Total" row in the report to the selected base currency.
  • When "Convert all figures to base currency" option is unchecked, all figures are displayed in original currencies (except the Total row).
  • Select the platform that Player used to place bets. Default value "All" is applied for this filter.
  • "Status" filter has Booking/ Successful/ Unsuccessful/ Cancelled.

Report Guidelines

  • External ID: The username registered by the ticket owner.
  • System ID: The Numeric sequential ID generated from the system for each account.
  • Booked ID: A unique reference number given to each Booked in the system.
  • Ref No: Display for Booked Successfully. A unique reference number given to each bet in the system.
  • Booked Time: The time and date when the booked is accepted.
  • Choice: Shows detail information of Bet ticket such as K.O date and time of the match (only for Sportsbook), bet type, selected team, match and league name.
  • Odds Lower: Displays the lower odds value of each booked ticket.
  • Odds Upper: Displays the upper odds value of each booked ticket.
  • Odds type: The odds format of each ticket.
  • Stake: The amount of money that Player has booked on each ticket.
  • Status: Shows the status of booked ticket.
  • Platform: The platform that Player used to place bets.
